BRC Cloud Setup - Build 2026.08.12.04.03

1. Deploy this build to GitHub Pages.
2. Open BRC > Settings > Cloud Sync (or click the Cloud status button).
3. Project URL should be:
   https://wbitcssptqllibnfcxsg.supabase.co
4. Paste the Supabase Publishable Key beginning with sb_publishable_.
   NEVER paste the Secret Key or database password into the app/GitHub.
5. Save Cloud Settings and allow the app to reload.
6. Click Login and sign in using a user created under Supabase Authentication.
7. The corresponding public.profiles row must be active and have the needed permissions (admin bypasses individual permission flags).
8. If the cloud inventory is empty and this device contains the existing local inventory, use Upload Local Inventory once.
9. Verify Supabase tables:
   - belt_catalog
   - inventory_balances
   - inventory_transactions
10. Sign in on a second device and confirm the same inventory appears and updates through Realtime.

Cloud behavior in 04.03:
- Supabase is the primary source after sign-in.
- Add/Edit Belt writes to belt_catalog.
- Add/Use/Set Balance uses the adjust_inventory RPC.
- History reads inventory_transactions.
- Realtime subscriptions refresh inventory/history on other devices.
- Product Delete archives belt_catalog.is_active=false to preserve transaction history.
- Local data remains a cache/recovery source; first-time migration is explicit and is never automatic over an empty cloud database.
